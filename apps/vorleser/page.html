Und als MP3?

Die Browser-Sprachausgabe spielt nur ab — sie gibt keine Datei heraus. Für eine echte Audiodatei nimmst du edge-tts: kostenlos, kein Konto, kein API-Schlüssel, und die neuronalen deutschen Stimmen klingen deutlich besser als die des Betriebssystems.

  1. Einmalig installieren (braucht Python):

    pip install edge-tts

  2. Text in eine Datei schreiben und umwandeln:

    edge-tts --voice de-DE-KatjaNeural \
         --file text.txt \
         --write-media hoerbuch.mp3

  3. Andere deutsche Stimmen ansehen:

    edge-tts --list-voices | grep de-
Welche Stimmen hier auftauchen, hängt vom Gerät ab: macOS und Windows bringen von Haus aus deutsche Stimmen mit, unter Linux muss meist erst eine installiert werden. Chrome liefert die besten Ergebnisse, Safari markiert die Wörter nicht mit.
